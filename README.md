# Трекер учебных задач

Локальное (offline-first) веб-приложение для отслеживания выполнения учебных задач по разделам: **Английский язык, Алгебра, Физкультура** (разделы редактируемые). Задачи проходят по статусам на канбан-доске: `Запланирована → В работе → Отложена → Выполнена`.

Разработка ведётся по этапам из `prompt-tracker-habit.md`.

## Команды

```bash
npm install        # установка зависимостей
npm run dev        # дев-сервер (http://localhost:5173)
npm run build      # типы + продакшен-сборка в dist/
npm run preview    # локальный просмотр продакшен-сборки
npm test           # прогон Vitest
npm run test:watch # Vitest в режиме watch
npm run lint       # ESLint
npm run format     # Prettier (форматирование всего проекта)
```

## Технологии

- Vite + React 18 + TypeScript (strict)
- Vitest + Testing Library + jsdom
- ESLint 9 (flat config) + Prettier
- Обычный CSS с дизайн-токенами (светлая/тёмная тема)
- Хранение: `localStorage` (реализуется на этапе 1), без бэкенда

## Структура

```
src/
  main.tsx          — точка входа, подключение стилей
  App.tsx           — оболочка: шапка, навигация, активный экран
  App.test.tsx      — smoke-тесты каркаса
  components/
    TabNav.tsx      — нижняя/верхняя навигация по вкладкам
    ui/Modal.tsx    — доступная модалка (портал, ловушка фокуса, Escape)
    sections/       — экран «Доска»: сайдбар, карточка раздела, формы, удаление
    board/          — канбан-доска: колонки статусов, DnD, меню перемещения
    tasks/          — список задач раздела, форма задачи, тесты
    today/          — экран «Сегодня»: дни, фильтр, прогресс, галочка, undo
    stats/          — экран «Статистика»: heatmap, серии, %, столбики, фильтр
    settings/       — экран «Настройки»: тема, неделя, экспорт/импорт, сброс
    ui/ConfirmModal.tsx — универсальное окно подтверждения
    ui/UndoToast.tsx   — undo-уведомление (role="status", кнопка «Отменить»)
  hooks/            — хуки (useActiveTab, useStore, useTheme, useUndoToast)
  lib/              — доменная логика:
    types.ts        — типы Section, Task, Store, статусы и их подписи
    dates.ts        — локальные даты YYYY-MM-DD (today, addDays, валидация)
    id.ts           — генератор id (crypto.randomUUID с запасным вариантом)
    seed.ts         — разделы по умолчанию и сид-задачи для разработки
    migrate.ts      — версии схемы, пошаговые миграции, валидация данных
    store.ts        — репозиторий поверх localStorage: чтение/запись/подписка
    sections.ts     — операции с разделами (create/reorder/archive/delete)
    tasks.ts        — операции с задачами (create/update/delete/move/setTaskStatus,
                      tasksByStatus для колонок, валидация)
    day.ts          — день: dayTasks (задачи дня), dayProgress («N из M»),
                      markTask/unmarkTask (галочка, прежний статус, запрет будущего)
    progress.ts     — прогресс: tasksProgress/sectionProgress (выполнено / активных),
                      weekStart/weekTasks/weekProgress (неделя по firstDayOfWeek)
    stats.ts        — статистика: dayStat/intensity (доля дня, уровень heatmap),
                      heatmapGrid (12 недель, будущие дни), streaks (серии подряд),
                      rangeProgress (7/30 дней), dailySeries (столбики), pluralDays
    settings.ts     — настройки: serializeStore/importStore (экспорт/импорт с валидацией),
                      applyTheme (data-theme на <html>), exportFileName
    tabs.ts         — константы вкладок
  styles/           — tokens.css (переменные тем; tokens.test.ts — автотест контраста WCAG),
                      global.css (база, кнопки, undo-тост),
                      sections.css (экран разделов, полосы прогресса, модалки), tasks.css (список задач),
                      kanban.css (канбан-доска и переключатель вида),
                      today.css (экран «Сегодня»: день, фильтры, прогресс дня и недели),
                      stats.css (экран «Статистика»: heatmap, карточки, столбики),
                      settings.css (экран «Настройки»: опции, ошибка импорта, сброс)
  test/setup.ts     — настройка Vitest (матчеры jest-dom)
```

- [x] **Этап 2 — Разделы:** сайдбар с тремя разделами по умолчанию и счётчиками задач, CRUD через доступную модалку (валидация имени 1–60 символов, выбор иконки и цвета), сортировка ↑/↓, архивирование, удаление с явным выбором судьбы задач (перенос в другой раздел / удаление), пустые состояния.
- [x] **Этап 3 — Задачи:** список задач выбранного раздела под карточкой (статус-бейдж, описание, срок), создание/редактирование через модалку (название 1–100 символов, описание, раздел, статус-радио, срок `type=date`), порядок ↑/↓, удаление с подтверждением, перенос задачи в другой раздел, пустое состояние.
- [x] **Этап 4 — Канбан:** четыре колонки статусов со счётчиками для выбранного раздела, drag & drop нативным HTML5 с подсветкой колонки-приёмника, меню «Переместить в…» на карточке (для клавиатуры и мобильных), оптимистичное обновление с откатом при ошибке, отметка `lastStatusChangeAt`, табы колонок на мобилке (без DnD), переключатель вида «Канбан / Список».
- [x] **Этап 5 — Экран «Сегодня» и отметка выполнения:** список задач выбранного дня (очередь на сегодня + отметки и сроки дня), навигация по дням с блокировкой будущего, фильтр по разделам, строка прогресса «N из M» с полосой, быстрая галочка (на экране «Сегодня», в списке задач и на карточке канбана), возврат прежнего статуса при снятии отметки, undo-уведомление.
- [x] **Этап 6 — Перемещение между разделами и прогресс:** drag & drop карточки на раздел сайдбара (подсветка-приёмник) и меню «Переместить в раздел…» на карточке и в списке (альтернатива для клавиатуры), предупреждение при переносе в архивный раздел, undo-уведомление «X → Y», полосы и проценты: по разделу (сайдбар + карточка), общий прогресс дня и недели на «Сегодня», мгновенный пересчёт.
- [x] **Этап 7 — Статистика:** heatmap активности за 12 недель (интенсивность — доля выполненных задач дня, клик по дню → список задач дня), текущая и лучшая серии подряд (streak), % выполнения за 7 и 30 дней, столбиковый график за 30 дней (CSS, без библиотек), фильтр статистики по разделу.
- [x] **Этап 8 — Настройки, экспорт/импорт, темы:** переключатель темы (системная / светлая / тёмная, `data-theme` на `<html>`, сохраняется), первый день недели, экспорт всех данных в JSON-файл, импорт с валидацией схемы и откатом при ошибке (текущие данные не теряются), полный сброс с двойным подтверждением (модалка + чекбокс).
- [x] **Этап 9 — Полировка, доступность, тесты:** адаптивность 320–1440 px (канбан табами и одна колонка на мобилке, сайдбар → селектор разделов с кнопкой «Все разделы»), ARIA для канбана и DnD (инструкция + live-регион о смене статуса), полная клавиатурная навигация и видимые фокус-стили, контраст ≥ 4.5:1 (автотест по токенам), пустые состояния на всех экранах, чистка мёртвого кода, финальный README.
